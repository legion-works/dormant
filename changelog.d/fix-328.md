Detail: The tray now closes its XDG portal session when releasing a global-shortcut claim, instead of dropping the handle and leaving the session live on the portal. Every accelerator rebind previously leaked one, so a long-running tray accumulated them. The same release path also runs when the refresh channel closes, which previously exited without unregistering the active claim.
